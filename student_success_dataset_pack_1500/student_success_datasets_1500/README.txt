STUDENT SUCCESS PLATFORM — SYNTHETIC DEMO DATA (1,500 STUDENTS)

Files:
- academic.csv: academic records and performance indicators
- attendance.csv: classes held/attended and attendance percentages
- lms_and_placement.csv: LMS usage, assignment completion, engagement, skills, and placement readiness

Row counts: 1,500 records per CSV.
Join key: student_id (shared across all three files).
Student IDs are fictional and consistent across the files.

Important:
- These are synthetic demo records, not real student data.
- A small number of metric values are intentionally missing for data-cleaning/testing.
- Scores are simulated for a hackathon prototype and must not be used to make real student decisions.
- Keep the three files in the same folder and merge on student_id.
